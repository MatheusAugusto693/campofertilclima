Como os dados funcionam

Transparência sobre a atualização

Atualização: o site consulta os serviços meteorológicos ao abrir e repete a consulta a cada 5 minutos enquanto a página estiver aberta.

Importante: “a cada 5 minutos” é a frequência de consulta do site, não uma garantia de que o modelo meteorológico seja recalculado nesse intervalo. Os dados são estimativas do Open-Meteo e podem ter atraso ou diferir da chuva medida no local. A chuva da última hora é calculada a partir dos valores horários disponíveis e não substitui uma estação pluviométrica.

Municípios: a lista é carregada da API pública do IBGE. É necessária conexão com a internet para buscar cidades e dados meteorológicos.
